# Python Command-Line Calculator

A command-line calculator built with Python. The calculator supports basic arithmetic operations, input validation, error handling, unit testing, and continuous integration with GitHub Actions.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling
- Invalid input handling
- REPL interface
- Parameterized pytest tests
- 100% test coverage
- GitHub Actions automated testing
